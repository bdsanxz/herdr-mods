# herdr-mods

[![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Community mods and agent integrations for [Herdr](https://herdr.dev), the desktop
app for running coding agents. Mods are small JavaScript modules written against
the runtime-provided `gpui-kit`, `gpui-base` and `herdr` modules.

## Contents

### Mods

| Mod | Description |
| --- | --- |
| [`auto-name`](auto-name) | Gives every new, unnamed tab a short robotic name (`Zyro`, `Kryx`, `Vexi`…) generated by [`@xzy-ai/robo-faker`](https://www.npmjs.com/package/@xzy-ai/robo-faker), skipping names already in use. Tabs that exist at startup or are named on creation are left alone. |
| [`titlebar-git`](titlebar-git) | An empty 38px header band that holds the native macOS window buttons, so layout content no longer collides with them. |
| [`workspaces`](workspaces) | A sidebar menu that lists spaces with their agents indented underneath. A space whose folder lies under another space's folder (same machine) nests as its child. |

### Integrations

Agents that do not report their state to Herdr appear as plain terminals. The
adapters in [`integrations/`](integrations) make them show up in the agents list
with a live status (`idle`, `working`, `blocked`, `done`), including "needs you"
indicators and notifications.

| Agent | Adapter | Mechanism |
| --- | --- | --- |
| OpenCode v2 | [`integrations/opencode`](integrations/opencode) | TUI plugin that maps session, permission and question events to the Program Status Protocol (OSC 7501). |
| Qoder CLI | [`integrations/qoder`](integrations/qoder) | Hook script (`SessionStart`, `UserPromptSubmit`, `PostToolUse`, `Notification`, `Stop`) that emits OSC 7501. |

See [`integrations/README.md`](integrations/README.md) for setup.

## Requirements

- Herdr (macOS)
- Node.js and npm, only for `auto-name` (it installs its dependency from `vendor/`)

## Installation

Mods live in `~/.config/herdr-app/mods/<name>/`.

```sh
git clone https://github.com/bdsanxz/herdr-mods.git
cp -R herdr-mods/workspaces ~/.config/herdr-app/mods/
herdr-app check workspaces
```

`auto-name` needs its dependency installed once:

```sh
cd ~/.config/herdr-app/mods/auto-name && npm install
```

Mods reload live. A broken mod keeps the previous version running and reports the
error in `herdr-app check`.

## Compatibility

The `gpui-kit`, `gpui-base` and `herdr` modules are injected by Herdr at runtime;
they are not npm packages and their API may change between Herdr releases. These
mods were written and tested against the Herdr build installed at the time of
writing; if a mod breaks after an update, open an issue.

## Scope

This repository contains only original work. Mods shipped with Herdr, and Herdr's
generated type definitions (`gpui-kit.d.ts`, `herdr.d.ts`), are not included and
are not covered by this license.
